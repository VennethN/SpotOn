    Validasi & Sumber

    Catatan mockup. Geometri peta, koordinat & nama stasiun, jalur MRT, jaringan jalan, dan jumlah POI pesaing per radius 800 m adalah data nyata dari OpenStreetMap (Overpass API, ODbL), diproyeksikan dengan Web Mercator sehingga lingkaran catchment berskala benar. Atribut khas dataset misi MAPID (Struk Go, Menu Go, Properti Go) bersifat contoh karena datanya tidak publik — strukturnya sengaja mengikuti kolom asli agar dapat langsung ditukar saat API MAPID tersedia bagi 50 tim terkurasi. Pada produk final, basemap wajib menggunakan MAPID MAPS.
